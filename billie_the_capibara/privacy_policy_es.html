Política de Privacidad

Última actualización: 01/08/2025

Esta aplicación fue desarrollada con el propósito exclusivo de realizar cálculos de conversión de unidades. La privacidad de los usuarios es una prioridad, por lo que esta política aclara que no se recopila, almacena ni comparte ninguna información personal.

1. Recopilación de Información

Esta aplicación no recopila datos personales del usuario. Esto incluye, pero no se limita a:

  • Nombre, dirección de correo electrónico o número de teléfono
  • Ubicación geográfica
  • Información sobre el dispositivo o comportamiento de uso

Los datos ingresados por el usuario para realizar conversiones se procesan localmente en el dispositivo y no se envían a servidores externos.

2. Permisos del Sistema

La aplicación solicita permiso para acceder al almacenamiento local del dispositivo. Este permiso se utiliza exclusivamente para guardar el último estado de las conversiones realizadas, lo que permite al usuario continuar con su uso de forma fluida. Ninguna de estas informaciones se comparte ni se accede por terceros.

3. Uso de la Información

Como no se recopilan datos personales, no se utiliza información con fines de marketing, análisis ni publicidad.

4. Compartición con Terceros

Esta aplicación no comparte datos con terceros, ya que no se recopila ni transmite ninguna información personal.

5. Seguridad

La aplicación fue desarrollada siguiendo buenas prácticas de seguridad, garantizando que los datos almacenados localmente permanezcan protegidos y sean accesibles únicamente por la propia aplicación.

6. Cambios en esta Política

Esta política de privacidad puede actualizarse ocasionalmente. Se recomienda que el usuario consulte esta sección periódicamente. Los cambios significativos se comunicarán a través de la interfaz de la aplicación.

7. Contacto

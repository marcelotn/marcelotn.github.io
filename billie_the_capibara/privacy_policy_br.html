Política de Privacidade

Última atualização: 01/08/2025

Este aplicativo foi desenvolvido com o propósito exclusivo de realizar cálculos de conversões de unidades. A privacidade dos usuários é uma prioridade, e por isso, esta política esclarece que nenhuma informação pessoal é coletada, armazenada ou compartilhada.

1. Coleta de Informações

Este aplicativo não coleta dados pessoais do usuário. Isso inclui, mas não se limita a:

  • Nome, endereço de e-mail ou número de telefone
  • Localização geográfica
  • Informações sobre o dispositivo ou comportamento de uso

Os dados inseridos pelo usuário para realizar conversões são processados localmente no dispositivo e não são enviados para servidores externos.

2. Permissões do Sistema

O aplicativo solicita permissão de acesso ao armazenamento local do dispositivo. Essa permissão é utilizada exclusivamente para salvar o último status das conversões realizadas, permitindo que o usuário retome o uso de forma contínua. Nenhuma dessas informações é compartilhada ou acessada por terceiros.

3. Uso de Informações

Como não há coleta de dados pessoais, não há uso de informações para fins de marketing, análise ou publicidade.

4. Compartilhamento com Terceiros

Este aplicativo não compartilha dados com terceiros, pois nenhuma informação pessoal é coletada ou transmitida.

5. Segurança

O aplicativo foi desenvolvido seguindo boas práticas de segurança, garantindo que os dados armazenados localmente permaneçam protegidos e acessíveis apenas pelo próprio aplicativo.

6. Alterações nesta Política

Esta política de privacidade poderá ser atualizada ocasionalmente. Recomendamos que o usuário consulte esta seção periodicamente. Mudanças significativas serão comunicadas por meio da interface do aplicativo.
